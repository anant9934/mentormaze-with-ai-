# MentorMaze — API Documentation

**Base URL:** `http://localhost:3000/api`  
**Authentication:** Cookie Session / JWT Authorization Header  
**Data Format:** JSON (`application/json`)  

---

## 1. Authentication & LiveKit RTC

### `GET /api/livekit/token`
Generates a short-lived (1 hour TTL) WebRTC participant access token for 1-on-1 mentorship or mock interview rooms.

**Query Parameters:**
| Parameter | Type | Required | Description |
|---|---|---|---|
| `bookingId` | string | Yes | ID of the confirmed booking |
| `userId` | string | Optional | User identifier (defaults to session user) |
| `userName` | string | Optional | Display name of the participant |

**Response (200 OK):**
```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "roomName": "mm-room-priya-anant-101",
  "wsUrl": "wss://mentormaze-dev.livekit.cloud"
}
```

## 2. Payments & Webhooks

### `POST /api/payments/webhook`
Handles Cashfree server-to-server transaction notifications. Verifies HMAC-SHA256 signature and applies idempotent updates to the marketplace ledger.

**Headers:**
- `x-webhook-signature`: HMAC-SHA256 signature generated by Cashfree
- `x-webhook-timestamp`: UNIX timestamp of the webhook event

**Payload Example:**
```json
{
  "type": "PAYMENT_SUCCESS_WEBHOOK",
  "data": {
    "order": {
      "order_id": "order_cf_booking-1",
      "order_amount": 249.00,
      "order_currency": "INR"
    },
    "payment": {
      "payment_status": "SUCCESS",
      "cf_payment_id": "cf_pay_98237489"
    }
  }
}
```

**Response (200 OK):**
```json
{
  "received": true,
  "status": "processed",
  "orderId": "order_cf_booking-1"
}
```

## 3. Core Domain Actions

All core business domains are accessible through typed service methods:
- `store.getTopRecommendedMentors(userId)`
- `store.createBooking(params)` (with concurrency locking)
- `store.verifyMentorApplication(appId, action, notes)`
- `store.sendMessage(conversationId, senderId, content)`
- `store.updateSettings(newSettings)`
- `store.getAnalytics()`
